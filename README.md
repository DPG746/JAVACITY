# JavaCity 🏙️

JavaCity is a Java Object-Oriented Programming project that simulates components of a small city.

## Features

This project demonstrates key OOP concepts:

- Encapsulation
- Inheritance
- Polymorphism
- Interfaces
- Composition

## Project Structure

Animals:
- Animal
- Dog
- Cat

Vehicles:
- Vehicle
- Car
- Bicycle

Buildings:
- Building
- ShoppingMall
- TinyHouse

Smart System:
- SmartRoom
- LightBulb
- Speaker

Energy System:
- PowerConsumer

## How to Run

1. Open the project in Eclipse
2. Run:
